## 🎮 Controls

### ⌨️ PC — Keyboard

| Key | Action |
|-----|--------|
| `A` / `D` | Move left / right |
| `W` | Jump |
| `W` `W` *(double-tap)* | 🤸 Flip Jump stunt! |
| `J` | Punch |
| `K` | Kick |
| `L` | Special Move *(needs full SP)* |
| `F` *(hold)* | Block |
| `Space` | Dodge — invincibility frames *(costs 22 SP)* |
| `T` | Taunt — gain SP & intimidate |
| `ESC` | Quit to menu |

### 📱 Mobile — Touch

Use the **on-screen D-pad** (▲ ◀ ▶) to move and jump.  
Use the **4 action buttons** (PUNCH · KICK · SP · BLK) to fight.  
The **SP button glows** when your special is ready!

## ⚔️ Combat System

| Mechanic | How it works |
|----------|-------------|
| ❤️ HP Bar | Drain enemy HP to win the round. Best of 3 rounds wins. |
| ⚡ SP Bar | Fills from hits & passively. Hit 100% → use your Special. |
| 🛡️ Block | Reduces damage to ~12%. Doesn't fully block Specials. |
| 💨 Dodge | Full invincibility. Costs 22 SP. Escape combos with this. |
| 🎯 Combo | Chain hits → combo multiplier → stunt labels at 5×, 8×, 12×+ |
| ⚠️ Rage Mode | Auto-triggers below 25% HP — red vignette effect. |
| ⏱️ Timer | Time out → higher HP fighter wins. Shorter on harder levels. |

## 📈 Progression

- **100 levels** — Beginner (1–10) → Easy (11–25) → Medium (26–45) → Hard (46–65) → Brutal (66–82) → Legendary (83–100)
- **Player XP & Level** — level up to Lv.100 MAX, earn XP every fight
- **Coins** — earned every fight; bigger rewards for wins, hard levels, and streaks
- **Win Streak Bonus** — consecutive wins multiply coins 🔥
- **Daily Challenge** — one special level per day gives **2× coin reward**
- **Auto-save** — saved to `localStorage` instantly after every fight
